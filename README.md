# Supply-Chain-Interactive-Dashboard
Supply Chain Performance Analytics Dashboard – Power BI
🔍 Overview
This project showcases an interactive Power BI dashboard designed to analyze and monitor key supply chain metrics, offering actionable insights into operations, procurement, and supplier performance.

📈 Key Features
Total Revenue: $110K
Products Sold: 8,662 units
Stock Level: 898 units
Supplier Defect Rate Analysis
Category & Region-Wise Sales Breakdown
Transportation Mode & Cost Analysis

🛠 Tools & Technologies
Power BI (Data Modeling & Visualization)
Power Query (Data Cleaning & Transformation)
DAX (Custom Measures & KPIs)
PowerPoint (Custom Dashboard Background Design)

🎯 Business Impact
Improved visibility into procurement, demand trends, and inventory levels.
Enabled supplier performance evaluation through defect tracking and cost breakdowns.
Empowered stakeholders with a clean, interactive UI including slicers, drill-throughs, and navigation buttons.

📌 Dashboard Includes
Doughnut Charts, Card Visuals, Bar/Column/Scatter Plots
Interactive Filters & Page Navigation
Clean, presentation-ready layout with custom backgrounds
